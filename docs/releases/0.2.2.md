# Identity V Assistant v0.2.2

修复旧配置升级后的快捷键冲突与恢复问题，改善 S0／S1 地图识别中小图标干扰墙体匹配的情况。

## 新增与优化

- S0／S1 识图过滤地图房间内部的小型明亮图标，减少宝箱、目标与玩家标记造成的匹配误差；保留墙体、边界和原有匹配门槛。
- 图标过滤范围随捕获分辨率调整，诊断记录包含被过滤的边缘数量，便于后续复核。

## 修复内容

- 旧配置或旧备份缺少楼层快捷键时，优先使用 F6，已被引擎或识图占用时选择空闲键；保留已有个人按键设置。
- 修复启动时快捷键注册失败后，纠正设置仍需重启的问题；保存时恢复缺失的引擎注册和地图监听，并复用已运行的监听。
- 修复地图内部图标被当成墙线导致无候选的情况。提供的两次 S1 噩梦与一次 S0 空结果，在离线回放中已能返回候选。

验证包括快捷键配置／备份回归、Windows 监听热更新、识图正反例与诊断回放。12 次完整回放中，原有 9 次非空候选列表及顺序保留，另 3 次恢复候选；候选未经玩家逐一确认，不能视为识别准确率。未进行真实游戏、账号登录或安装升级验证。
