# Identity V Assistant v0.1.6

加入游戏启动页与独立登录组件管理，完善窗口恢复、日志和手记体验。历史安装包保留原许可。

## 新增与优化

- 自动定位游戏，支持配置扫描、组件下载、后台代理及启动前更新检查。
- 增加统一更新确认、热更新、自动测速选源与启动取消，展示代理阶段和健康状态。
- 普通启动保持游戏窗口；启动引擎才应用布局，停止服务时恢复并重试失败操作。
- 支持关闭到托盘、点击托盘恢复，保留关键日志并提供开发者细节。
- 顶部提示支持短暂停留后淡出、悬停和聚焦保留；手记静默记住选择，每次进入重置楼层。

## 修复内容

- 修复代理退出后仍显示就绪的状态问题。
- 修复快捷键占用导致无关设置无法保存的问题。
- 修复开发启动路径错误和窗口退出顺序问题。
