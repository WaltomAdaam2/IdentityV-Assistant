# Identity V Assistant v0.1.11

新增加页手记一楼地图识别与位置记忆，完善会话诊断导出，并优化识图、日志和现有桌面控件。

## 新增与优化

- 支持按钮及默认 P 键识别当前赛季、难度的一楼地图；独立捕获游戏窗口，不启动自动化服务、不改变游戏窗口布局或抢走游戏焦点。
- 按匹配顺序最多展示四张候选，标明门型与编号；可记住“自动进入最匹配地图”选择，开启后直接进入第一名的全窗口地图预览。
- 识别时显示截图、定位和匹配进度，在等待区域居中展示暂定裁剪图；支持取消，筛选变化或离开页面会丢弃旧请求。
- 全窗口地图支持拖动、方向键移动及左上／右上／居中／左下／右下位置预设，跨地图和重启记忆位置；保留安全边界，楼层和关闭控件始终可操作。
- 诊断导出采用“选择会话 → 预览 → 保存 ZIP”，默认仅当前会话，可追加历史会话。截图开关统一控制所选会话；图片保留三天，日志与识图文字报告保留七天，设置提供目录入口。
- 每次识图分别保留完整截图、裁剪与处理图、实际模板及各地图评分、排除原因、耗时和取消记录；提供开发者离线重放命令。
- 识图使用最多两项并行的模板搜索，合并诊断记录写盘，减少重复清理扫描和日志列表处理；离线对照保持候选、排序、裁剪及评分一致。
- 细化按钮尺寸、圆角、辅助文字、键盘焦点和诊断会话选择反馈，保留现有米色／橄榄绿设计及导航、卡片动效。

## 修复内容

- 改善地图区域定位，排除图例、柜子和任务图标等干扰，保留细长地图结构，并以同一完整区域比较候选，减少局部片段误匹配。
- 修复诊断导出混入旧会话图片及遗漏识图证据的问题；明确列出缺失资料，按完整图片组选择证据，追加历史会话时取消总大小上限。
- 修复诊断截图偏好离开页面后丢失的问题，自动保存并在重启后恢复；诊断包文件名加入日期和时间。
- 修复登录组件热更新下载未沿用所选代理源的问题，保留原有校验、备份和回滚流程。
- 将识图阶段、取消和失败等操作统一接入持久化运行日志；普通与开发者模式使用同一份脱敏记录。

本版完成构建、离线和模拟界面验证，未进行原生安装、登录或实机对局验证。地图候选仍需结合实际画面核对。部分非登录任务异常及组件热更新“记录未保存”报错仍待排查，本版不声明已解决。
