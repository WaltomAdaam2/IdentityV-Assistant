# Identity V Assistant v0.1.7

将源码、历史发行与后续更新统一到 IdentityV-Assistant 仓库，修复地图导入反馈并完善中英文说明。自有源码与本版本采用 GPL-3.0-only；第三方材料及历史安装包保留原许可。

## 新增与优化

- 统一正式更新、预发布、测速、项目链接及发布脚本，旧下载仓库提供兼容 0.1.2–0.1.6 的一次过渡更新。
- 迁移历史安装包和签名，保留原始字节；发行说明采用完整变更记录并在末尾列出附件 SHA-256。
- 重整中英文 README，增加分开的功能逻辑、开发和发布文档，补充作者来源与许可边界。

## 修复内容

- 修复 Rust 格式检查导致 GitHub CI 失败，并将现有前端日志测试纳入 CI。
- 地图导入结果接入顶部提示条，保留成功数量和失败原因；切换页面、滚动页面和重复操作后仍能看到反馈，错误提供更长阅读时间。
- 修正不存在的默认 dry-run 和自动失败截图说明，移除没有实际功能的截图保存开关。

- 修复嵌套 PowerShell 打包后哈希命令不可见的问题；查看构建帮助或版本不再改写更新清单。
