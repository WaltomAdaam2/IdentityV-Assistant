# Identity V Assistant v0.1.5

改进诊断引擎的生命周期，更新已确认的应用图标。历史安装包保留原许可。

## 新增与优化

- 图标保留原有配色、米白底板和完整图案，清除边缘杂点及多余透明留白。
- 更新来源将 GH-Proxy 标注为推荐选项，默认仍为 GitHub 直连。

## 修复内容

- 检测窗口和捕捉完成后关闭仅为诊断临时启动的引擎，原先已运行的引擎继续保留。
- 修复诊断结束时误关期间由用户启动的引擎或任务。
