# Identity V Assistant v0.1.9

补充任务运行反馈与启动检查，增加本地配置备份和诊断导出，并修复登录组件热更新缺少下载信息的问题。

## 新增与优化

- 任务侧栏显示阶段、任务及阶段有效用时、暂停原因和下一步提示；暂停时间不计入有效用时。
- 新任务或任务队列自动检查游戏窗口、响应状态和画面捕捉，失败时提供重新检查与诊断入口。
- 默认开启失败截图，每次失败最多保存一张最近成功的 WGC 游戏窗口画面，保留拍摄时间；最多 20 张、100 MiB，可在设置关闭。
- 设置页支持导出配置、导入差异预览和确认恢复；恢复前保留原配置，任务运行或暂停时禁止恢复。
- 诊断 ZIP 可预览文件清单和大小，包含本次会话日志、必要环境及脱敏设置；截图单独选择，始终由用户保存和分享。
- 登录组件热更新显示逐模块已下载大小、可靠总量、速度及预计剩余时间，区分准备、下载、应用与代理恢复阶段。

## 修复内容

- 修复组件更新仅显示不确定进度条、无法查看实际下载量的问题；未知长度不再被当作确定的总量。
- 防止恢复设置后旧的自动保存覆盖新配置，校验外部备份字段并拒绝导出到助手运行数据目录。
- 修复保存失败截图期间停止任务可能再次进入暂停、导致停止无法完成的问题。
- 自动失败截图排除屏幕区域捕捉，避免在游戏被遮挡时保存其他窗口内容；写图失败不阻止任务停止。
