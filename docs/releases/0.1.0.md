# Identity V Assistant v0.1.0

首个 Windows x64 安装版，包含桌面界面、独立 Python 引擎、OCR 模型和识别素材。

## 新增与优化

- 提供中英文安装向导，可选择安装目录并创建开始菜单、桌面快捷方式。
- 集成引擎和识别依赖，用户无需另装 Python；缺少 WebView2 时由安装器下载。
- 配置、日志、截图和导入地图保存在本机 AppData。

## 修复内容

- 首次公开发布，没有上一公开版本的修复记录。
