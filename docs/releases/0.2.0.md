# Identity V Assistant v0.2.0

新增 S0 自动／手动难度与 S1 当前楼层识图，整合内置地图和组件更新，并完善日志与地图操作。

## 新增与优化

- 内置 S0 困难 29 张、噩梦 26 张合并地图，包含纯净与速刷图；新增 S1 磷光症困难 14 张、噩梦 15 张地下1至3层纯净图。启动时静默补齐，核验后的旧包先备份迁移，自定义内容保留。
- S0 难度新增默认“自动”：按截图楼层标志判断困难／噩梦，支持新版竖排及旧版横排；手动选择后按所选难度匹配，仍只识别一楼。
- S1 手选难度，自动判断当前地下1、2或3层，只匹配并展示该层；无法确认或选中地下4层时提示重试。
- S1 导入对应难度的速刷地图包后开放速刷选项；S0、S1 分别记住显示选择。
- 登录组件完整更新在助手内完成下载、校验、安装及配置，使用官方最新发布，显示下载量、速度与剩余时间；模块热更新一律跳过。
- 普通运行日志简化例行进度、快捷键和自动保存提示，开发者模式及诊断包保留完整记录；应用双语提示按设置显示一种语言。
- README、窗口标题栏和关于卡片新增 QQ 交流与反馈群 1131511789；关于卡片可打开加群邀请链接，并同步中英文使用说明。

## 修复内容

- 识图中再次按 P 会取消旧请求，待旧进程退出后重新截图；连续触发只执行最后一次，旧结果不会覆盖新结果。
- L 仅在“进入地图”的全窗口预览中切换可用楼层，列表、详情页及输入框内不触发；不操作游戏或抢走游戏焦点。
- 移除托盘图标，关闭窗口退出助手，最小化留在任务栏；重复启动恢复已有窗口。
- 启动时组件更新检查失败仍继续使用已安装组件；只读检查可关闭。启动提示支持手动关闭、两秒停留及半秒淡出收起。
- 组件下载可取消，配置与代理恢复期间阻止关闭；失败时尝试恢复原配置及助手持有的代理，保留账号和外部组件。
- 修正普通组件状态被记为警告、带换行的启动说明未被降噪，以及单语言错误提示丢失动态字段名的问题。
- 修正离线重放耗时说明，区分识图计时与进程启动，不把重放耗时作为实际游戏识图耗时。

本次验证使用离线测试、模拟界面及诊断截图；真实 S1 样本覆盖地下1层，地下2、3层仍需实机确认。未验证原生登录、游戏操作和安装升级；识图候选仍需用户核对。
