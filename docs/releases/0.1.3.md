v0.1.3

引擎稳定性
• 修复 Windows 安装版使用中文窗口名称时，因输出编码不一致导致引擎退出的问题。
• 引擎通信统一使用 UTF-8；异常编码会记录错误，不再静默关闭通信管道。

设置与更新
• 每项设置使用独立边框卡片，包含图标、标题、说明和控件。
• 开关增加“开 / 关”状态文字，保留助手现有配色。
• 更新弹窗更紧凑，显示当前版本、更新源、发布通道和检查结果。
• 默认使用 GitHub 直连，代理明确标为 GH-Proxy；保留已保存的更新源选择。
• 删除窗口位置下方重复说明，程序图标配色与助手主题一致。

加页手记
• 在“进入地图”旁及全窗口预览底部增加地下室、1F、2F 切换。
• 切换楼层时保留当前地图编号及纯净 / 速刷模式，没有的楼层会禁用。
• 保留 Esc 先退出预览、再次返回地图列表的操作。

安装会保留 AppData 中的设置、日志和地图包。此版本未进行实际游戏对局验证。
