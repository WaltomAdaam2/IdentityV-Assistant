# Identity V Assistant v0.2.0（待合并）

## 更新与修复

- 识图先检查完整地图右上角的楼层标志：`1、2` 使用困难地图池，`-1、1、2` 使用噩梦地图池，并同步手记难度。标志不清楚时停止并提示重试，不使用手动难度猜测；仍只识别一楼。
- 识图期间再次按 P 会取消旧请求，等旧进程退出后重新截图；连续触发只执行最后一次请求，旧结果不会覆盖新结果。
- L 切换助手当前地图的楼层：噩梦地下室→一楼→二楼，困难一楼→二楼。游戏或助手在前台时可用，不操作游戏、不抢焦点，助手输入框内不触发。
- 内置合并后的 S0 困难 29 张、噩梦 26 张地图，包含纯净与速刷展示。启动时静默补齐，已核验的旧来源包先备份再迁移；自定义包和修改过的内容保留，过程记录在运行日志。
- 跳过所有登录组件模块热更新。完整组件更新只安装已适配、固定大小及 SHA-256 校验通过的版本；下载、解包和配置在助手内完成，显示下载量、速度与剩余时间。
- 组件下载可取消，配置和恢复代理期间不可取消；操作结束前不能关闭更新弹窗或退出助手。配置失败尝试恢复旧配置和助手持有的代理，保留账号和外部组件。
- 移除托盘图标，关闭窗口退出助手，最小化保留在任务栏；重复启动显示已有窗口。
- 修正普通组件状态被记为警告的问题，更新源返回非 JSON 时提供切换源重试提示。

## 验证范围

已进行 Python／Rust 离线测试、前端类型检查与构建、模拟界面交互和现有诊断截图回放分析。未运行原生助手、真实登录、游戏对局或安装升级；新 HUD 布局与真实组件替换仍需实机验证。本轮仅提交未合并 PR，不生成安装包。

## English

- Detect difficulty from visible floor labels before first-floor matching; reject unclear labels instead of falling back to the browsing filter.
- Restart recognition with P after the cancelled helper exits; use L to cycle the assistant map's available floors without activating the assistant or controlling the game.
- Bundle 29 hard and 26 nightmare S0 maps with both artwork styles; silently fill missing content, back up verified original packs, and preserve custom changes.
- Skip all module hotfixes. Install only a pinned compatible full login component with transfer progress, cancellation before configuration, and rollback attempts on failure.
- Remove the tray icon, exit on close, and activate the existing window on repeated launch.
- Correct component log severity and explain invalid update-source responses.

Validation covers offline tests, frontend build and mock UI only. Native login, game behavior and installation/upgrade remain unverified. This iteration is an unmerged PR without installer artifacts.
