# Identity V Assistant v0.1.1

加入软件内更新和下载校验，个人配置、日志与地图继续保存在 AppData。

## 新增与优化

- 新增软件更新设置，支持 GitHub 直连、GH-Proxy 和启动版本检查。
- 下载与安装由用户确认，下载可取消；安装前校验签名、签名内版本、SHA-256 和文件大小。
- 更新前停止自动化并释放输入，保留本地数据。
