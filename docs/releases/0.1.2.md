v0.1.2

更新与下载
• 改用独立公开发布仓库，提供 GitHub 直连与免费代理。
• 下载文件使用随机名称；保留签名、版本、SHA-256 和大小校验。
• 启动发现新版本后展示更新日志，可选择此版本下次不再提示。
• 设置中提供预发布通道、更新源与手动检查。

设置与界面
• 设置改为一行一项，布尔选项使用开关。
• 新增游戏路径、开机启动、最小化托盘、缩放和引擎快捷键设置。
• 关于移至设置底部，增加日志目录入口。
• 保存成功提示悬浮三秒后淡出，启动背景改为浅色。

安装与许可
• 安装目录可以自选；配置、日志和地图保留在 AppData。
• 新版本自有代码使用个人使用专有许可，禁止未经许可转载或分发。
• 第三方许可证和历史 GPL 权利保留；必要的第三方源码随安装包提供。
