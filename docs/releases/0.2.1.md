# Identity V Assistant v0.2.1

新增楼层切换快捷键设置，精简手记提示，并减少代理启动后短暂忙碌造成的不可用提示。

## 新增与优化

- 设置中在“地图识别快捷键”后新增“楼层切换快捷键”，默认 F6，支持 A–Z 和 F1–F12，保存后立即生效并在重启后保留。
- 识图、楼层切换和引擎快捷键互斥，界面禁用冲突选项，设置保存和恢复也会校验。
- 手记说明同步显示当前楼层快捷键；仍仅在全窗口地图预览中切换助手显示的楼层，不操作游戏或切走游戏焦点。

## 修复内容

- 删除难度筛选下“自动判断识图难度；当前浏览……”提示，保留自动／手动难度功能和 S1 地下楼层检测。
- 代理通过启动检查后，短暂健康检查失败显示“正在检查”；连续失败至少十秒才报告不可用，成功后重置等待。进程退出及代理模式／版本错误仍立即报告。
