# Identity V Assistant v0.1.4

完善地图导入和更新设置，采用可读安装包名称。历史安装包保留原许可。

## 新增与优化

- 地图 ZIP 支持多选导入，楼层切换不再保存设置。
- 新增启动自动检查开关以及 GHFast、ghproxy.net 更新来源。
- 更新橡木色手记图标，统一标题栏、品牌与关于卡片。
- 增加恢复默认窗口大小，窗口尺寸静默保存。

## 修复内容

- 避免临时楼层切换和窗口尺寸保存触发多余设置提示。
