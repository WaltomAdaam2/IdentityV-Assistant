# Identity V Assistant v0.1.8

完善下载进度与更新日志的阅读体验，移除自动测速选源，并将版本交付改为永久保留的 SNAPSHOT 分支和人工审核发布的草稿流程。

## 新增与优化

- 在下载进度条右侧显示实时速度和预计剩余时间，使用最近五秒的实际传输数据更新估算。
- 更新日志支持 Markdown 标题、列表、强调、代码和链接，保留可滚动阅读区域。
- GitHub 直连标记为默认来源，保留 GH-Proxy、GHFast 与 ghproxy.net 手动选择。
- 新增统一 PR 和 Release 格式文档；每版本独立 SNAPSHOT 分支，合并后永久保留并冻结。
- 更新中英文 README 的居中项目介绍、导航、真实徽章和两张用户提供的演示图。

## 修复内容

- 移除自动测速请求、选源缓存及相关界面选项，旧自动配置迁移为直连。
- 下载停滞或大小未知时不再展示无依据的剩余时间，取消后重试会重新采样。
- 发布脚本只上传 Draft Release，核对版本分支及构建提交后交由用户亲自审核发布。
