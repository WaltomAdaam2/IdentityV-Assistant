# Issue tracker: Local Markdown

Issues and specs live in this repository under `.scratch/`.
- One feature per directory: `.scratch/<feature-slug>/`.
- Specification: `spec.md`; implementation issues: `issues/<NN>-<slug>.md`, one file per issue.
- Each issue records `Status:`, `Type:`, and any `Blocked by:` issue numbers.
- Use the triage vocabulary in `triage-labels.md`; use `claimed` and `resolved` for execution state.
- Record decisions and verification under `## Progress`; append discussion under `## Comments`.
- When a skill says to publish or fetch a ticket, write or read these files, not GitHub Issues.
- An effort may use `map.md` to index child issues and decisions. Resolve a ticket only with evidence.
